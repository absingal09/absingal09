# 🎨 Pixel canvas

A shared 150×150 pixel canvas. It starts as a pixel-art Ferrari F40 and anyone with a
GitHub account can paint one pixel every 5 minutes. Preserve it, add to it, or paint over it.

### [🎨 Paint a pixel](https://absingal09.github.io/absingal09/pick.html)

Click the pixel you want on the [picker](https://absingal09.github.io/absingal09/pick.html), pick a colour, and it opens a pre-filled issue — or use the [plain form](https://github.com/absingal09/absingal09/issues/new?template=pixel.yml) if you already know the X/Y. Each person may paint **once every 5 minutes**; overpainting an existing pixel is fine.
